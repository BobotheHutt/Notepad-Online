# Notepad+ Web App

A clean, blazing-fast, distraction-free word processor built as a free alternative to Microsoft 365 core document drafting tasks. 

## Features
- **Rich Text Controls:** Native formatting bold, italics, underline, and layouts.
- **Accessibility Integration:** Native Text-to-Speech audio proofreader.
- **Live Metrics:** Real-time character and word count tracking.
- **No Installations:** Runs instantly in any standard desktop or mobile browser.

## How to use locally
1. Download or clone this repository.
2. Double-click `index.html` to launch it immediately in your web browser.
